Sunset Press — an offline browser app that turns your photos and a caption into GTA 6-style cover art: multi-panel posters, Vice City neon-sunset grades, bold gradient lettering, one-click PNG exports in three post sizes. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8080/ in desktop Chrome. No build step, no network: `node main.ts` hands the app in by copying `app/` and `screenshots/` to `/output` and writing the dossier.
